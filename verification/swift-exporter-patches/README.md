These seven source diffs preserve the isolated Kotlin 2.4.20 exporter investigation against JetBrains/kotlin revision `890ac1d94fdb80eb85f0eeb5be5e4352df987b2f`. `provenance.json` identifies exact upstream paths, source hashes, patch hashes and six original Git blobs. The header baseline is pinned from the official exporter resource; its Git blob is independently unverified. This directory contains diffs rather than a Kotlin source checkout or compiler binary.

The ordinary RuntimeSupport repair uses an internal bridge import and an immutable String diagnostic. It captures the diagnostic at the boundary instead of storing a non-Sendable KotlinBase in Swift.Error. The other diffs cover concrete callback carriers, managed coroutine results, cancellation and caller-inheriting async declarations. Apply each diff to its exact upstream path at the recorded revision; do not apply them to generated consumer output.
