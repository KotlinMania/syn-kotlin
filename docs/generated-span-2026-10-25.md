# Generated span.rs adoption

The complete original `tmp/syn/src/span.rs` (63 lines, 12 items, no configured-out
items) is generated by rust-kotlin's existing proc-macro2/Syn frontend. `Span.kt`
is raw generated output plus its package/header and ktfmt formatting; its body
matches ktfmt(raw) exactly. No hand-written semantic patch was applied.

The source trait is an interface. Nine concrete result-specialized implementations
are explicit adapter classes, since Kotlin cannot add these interfaces to foreign
classes. Three immutable fixed-array types retain the distinct lengths and Copy
elements. This deliberately replaces the old List-based helpers rather than
retaining a parallel hand-written implementation. Six Brace/Bracket/Paren factory
calls now instantiate the generated span-to-delimiter adapter. TokenMarker's
uninhabited trait method uses the source method name `into_spans`; its behavior
is unchanged. Workspace search found no external imports of the removed helpers.

Rust source is the oracle. Raw output compiles with warnings as errors and matches
28 observations across all nine implementations, Unicode source positions,
delimiter boundaries, and Copy isolation. The old published helpers return shared
mutable Span wrappers: changing a returned value or array element can change
another. Saved probes reproduce both differences. These are public helper
contract differences; no claim is made that current production callers perform
those mutations. The generated code copies wrappers and passes the comparisons.

The required proc-macro2 Span.clone repair retains immutable backend data rather
than reparsing tokens. It is locally published as 0.1.7 and passes 70 JVM/70 macOS
tests. Existing dependency configuration was preserved. Syn's adoption passes
430 JVM and 428 macOS tests, including three new span regression methods. These
counts are tests on this port, not whole Syn translation coverage.

Evidence: `../rust-kotlin/docs/syn-emission-19.md`, its validation JSON, and
`../rust-kotlin/tmp/syn-emission-19/` (exact source/output snapshots, ordinary raw
and formatted diffs, generator/library hashes, caller migration and test logs).
Rust comparisons live in `../rust-kotlin/tmp/syn-span-qd_a9ss6/`.

Limits: fixed arrays admit nonborrowed Copy elements and literal lengths 0–127;
mutation/indexing/repeat/const-expression emission is not implemented. Trait
bounds/defaults/blanket impls/trait objects and generic dispatch are not covered.
Compiler-host hygiene, other platform execution and foreign ABI are unverified.
No targets or version pins were changed; no remote actions were performed.
